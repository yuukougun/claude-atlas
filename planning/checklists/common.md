- 照らす規則は、執筆の手引き（planning/guides/common.md と型の手引き）にある。ここには、4つの観点に共通の決まりだけを置く。直し方は planning/guides/README.md にある
- 項目の横の「（検査：<名前>）」は今ある検査、「（作る予定：<名前>）」はまだない検査である

## 2. 見方

元：design §10.2・§6.11、research/20 の D2

- 書いた本人の説明を根拠にしない。一次資料・計算・検査の結果・実行の結果で確かめる
- 描画した結果を見る。Markdown だけを読んで済ませない（作る予定：render_pages.py）
- 担当の外への波及（並べ替えた後の「上の節」など）は、メインと道具の検査が見る。気づいたら「メインに判断してほしいこと」に書く
- 照らすのは、手引きの今の版の規則である。手引きと設計書・決定が食い違って見えたら、指摘にせず「メインに判断してほしいこと」に書く
- 印のある規則は、検査の結果を見て、通らなかったものを指摘にする。印のない規則は、自分で読んで確かめる
- Web：atcoder.jp・codeforces.com は開かない。新しいドメインは、`uv run python tools/check_noai.py <URL>` で確かめてから読む（検査：check_noai.py）
- 文書にない回避方法に気づいたら、その方法を指摘にも報告にも書かない（報告も公開のリポジトリに残る）。「この記述（雛形）は文書にない回避方法に触れているので、触れない形に直す」とだけ書く（共通の手引き §14）

## 3. 指摘の形

元：design §10.2・§10.3

指摘は表にし、1件を1行に書く。

| # | 場所 | 項目 | 内容 | 根拠 | 直し方の案 | 重さ |
| --- | --- | --- | --- | --- | --- | --- |

- 場所：節の anchor か行。雛形と図は、ファイルの名前と行
- 項目：チェックリストの番号（F1・T1・U1・G1 など）
- 根拠：出典の URL と読んだ所、計算、流したコマンドとその結果
- 重さ：必須（事実の誤り・規則に反する・読者を誤らせる）か、推奨（直すとよくなる）

## 4. 段階を動かす

元：design §10.2・§3.3・§9.2

- 検証役は本文を直さない。直しは、書いた担当に戻す
- 直しの後は、指摘ごとに直しの差分を確かめ直し、解決か未解決かを書く。解決とは、必須の指摘が直ったこと、推奨の指摘が直ったか、直さない理由が直しの報告にあること、である
- reviewed にするのは、そのページに当てたすべての観点（雛形や図のないページは、その観点を当てない）の指摘が解決したときである。それを確かめた検証役（ふつうは、直しの差分を最後に確かめ直す担当）が、front matter の `stage` を `reviewed` にし、同時に `verified` と `verified_with` を書く
- `verified` は、事実・出典・鮮度の検証役が出典を読み直して確かめた日である。事実・出典・鮮度の検証役は、この日と確かめた版を報告に書く
- `verified_with` は、そのとき確かめた版（`{claude_code, channel, models, app}`）である。channel は latest か stable で、試していない項目は書かない（形は `schema/page.schema.json`）
- 未解決の指摘が残るなら、段階を動かさない
- done にするのはメインである（検査が0件で、未解決の指摘がないことを確かめる）

## 5. 報告の形

元：design §10.3

報告はファイルに書いてから終える（置き場所は指示に従う）。見出しはこの順に置き、書くことのない見出しも残して「なし」と書く。「確かめていないこと」は空にしない。

```markdown
# 検証の報告：<観点>（<ページの id>）

- チェックリストの版：共通 <版>・観点 <版>

## 1. 指摘の一覧
## 2. 確かめたこと
## 3. 段階
## 4. 止められた操作
## 5. メインに判断してほしいこと
## 6. 確かめていないこと
## 7. 使用量
```

- **確かめたこと**：読んだ出典（URL と読んだ日）、流した検査（コマンドと結果）、描画を見た環境（ブラウザの版・幅・ライトとダーク）、確かめた Claude Code の版と系列
- **段階**：reviewed にしたか、しなかった理由
- **使用量**：道具の呼び出しの回数・Web の取得の回数・かかった時間（分かればトークン）
