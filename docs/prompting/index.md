# 頼み方

- [理由を添える](give-reasons.md)（使う・下書き）：規則や依頼に理由を添えると、Claude は書いていない場面にも意図を当てはめられる。
- [具体性の 4 点（対象・状況・完了・手本）](four-specifics.md)（整える・下書き）：依頼に対象・状況・完了の形・倣う手本の 4 点を書くと、Claude が推測で埋める所が減り、意図とのずれが減る。
- [例を見せる](show-examples.md)（整える・下書き）：形や文体は言葉で説明するより、典型的で多様な例を見せるほうが揃う。
