# 頼み方

## 頼み方の原則

- [新人の同僚に頼むつもりで](brief-a-new-colleague.md)（使う・下書き）：Claude は会話の外の事情を知らないものとして頼むと、依頼に何を書き足せばよいかが分かる。
- [理由を添える](give-reasons.md)（使う・下書き）：規則や依頼に理由を添えると、Claude は書いていない場面にも意図を当てはめられる。
- [具体性の 4 点（対象・状況・完了・手本）](four-specifics.md)（整える・下書き）：依頼に対象・状況・完了の形・倣う手本の 4 点を書くと、Claude が推測で埋める所が減り、意図とのずれが減る。
- [例を見せる](show-examples.md)（整える・下書き）：形や文体は言葉で説明するより、典型的で多様な例を見せるほうが揃う。
- [否定形ではなく、望む形で書く](say-what-you-want.md)（整える・下書き）：「〜するな」より「〜で書け」と望む形を示すほうが守られやすい。
- [強調語（IMPORTANT・必ず）の現在](emphasis-words.md)（整える・下書き）：強調語を重ねても指示は守られるようにならず、強い言い方はかえって過剰に当てはめられることがある。

## 何をどこまで頼むか

- [提案してほしいのか、実行してほしいのか](suggest-or-do.md)（整える・下書き）：提案だけか、実行までか、懸念があれば止まって相談するのかを動詞で書き分けると、勝手に書き換えられることも提案で止まることも減る。
- [範囲を伝える（やらないこと）](state-the-scope.md)（整える・下書き）：依頼に、やること・やらないこと・触ってよい範囲を書くと、頼んでいない機能や変更が増えにくくなる。
- [細かく指図するか、成果で頼むか](ask-for-outcomes.md)（任せる）：目的と完了の条件は測れる成果として渡し、どこを攻めるか・何で測るかは具体的に書く。
- [目標値・上界を伝える](share-targets-and-bounds.md)（任せる・下書き）：達成できる値や理論上の上界が分かっていれば依頼に書くと、早く打ち切ったり「限界です」と言ったりしにくくなる。
- [出力の形と分量を指定する](output-shape.md)（整える・下書き）：書式・長さ・要約の有無は望む形で指定し、頼む文の書き方も出力の形に合わせる。
