知識マップは、この辞典のページどうしの前提関係を図にしたページである。図は道具が各ページの情報から作るので、このページに手で描いた図はない。

## 地図の見方 {#how-to-read}

知識マップの線は、2 種類の関係から引かれる。

- **前提**：そのページを読む前に分かっていると読みやすいページへ向かう線。各ページが持つ前提の指定から作る。
- **振り分け**：症状のページから、原因ごとの対処のページへ向かう線。症状のページの診断で、疑う原因に応じて行き先が分かれる。

載せるのは、下書き以上の段階にあるページだけである。骨格だけで中身のないページと、まだ公開していないページは図に出ない。図に出ないページは、公開した時点で現れる。

図は 3 通りの見方がある。

1. **分野ごとの表示**：分野を選ぶと、その分野のページとつながりが見える。全体を見渡して、どこから読み始めるかを決めるのに向く。
2. **選んだページの祖先と子孫だけの表示**：ページを 1 つ選ぶと、そのページの前提をさかのぼったページ（祖先）と、そのページを前提にするページ（子孫）だけに絞られる。「このページの前に何を読むか」と「このページの次に何が読めるか」を同時に確かめられる。子孫が多いときは、深さを絞った状態から始まる。関連のページは、点線の囲みで足される。
3. **全体の表示**：分野を 1 つの点にして、分野どうしのつながりを見る。線の太さは、分野をまたぐ線の本数である。分野を押すと、その分野の表示になる。

!!! example "判断例：前提が多いページを読む前に"
    - **状況**：読みたいページがある。前提のページが何本もつながっていて、どこまで読めば足りるか分からない。
    - **迷う候補**：前提を全部さかのぼって読む。読みたいページから読み始め、分からない語が出た所で前提に戻る。
    - **選んだもの**：選んだページの祖先だけの表示で前提の数を確かめる。少なければ前提から読み、多ければ読みたいページから読み始める。
    - **理由**：どちらの読み方も筋が通る。前提が少しなら、先にさかのぼるほうが迷わない。前提が多いなら、分からない所だけ戻るほうが早く着く。祖先だけの表示は、どちらにするかを決める材料になる。

## ほかの地図との使い分け {#choose}

知識マップは、ページの前後関係を見るための地図である。何を引くかによって、ほかの入口のほうが早く着く。

| 知りたいこと | 引くページ |
| --- | --- |
| 困りごとや、やりたいことの言葉から、読むページを探したい | <!-- link:begin reverse-index -->[逆引き辞典（症状・やりたいこと・状況）](reverse-index.md)<!-- link:end --> |
| 今の自分の段階から、次に読む順と、人が握るものを知りたい | <!-- link:begin roadmap#reading-order -->[ロードマップ（委任の段階別） › 段階ごとのページの列](roadmap.md#reading-order)<!-- link:end --> |
| 辞典そのものの引き方と、バッジや確認日の読み方を知りたい | <!-- link:begin how-to-use -->[この辞典の引き方](how-to-use.md)<!-- link:end --> |

前提の線は、読む順の目安であり、必ず守る順序ではない。段階ごとに読む順の整理は、<!-- link:begin roadmap#levels -->[ロードマップ（委任の段階別） › 五つの段階と上がる条件](roadmap.md#levels)<!-- link:end --> が持つ。
