出典と AI 利用の方針は、この辞典が AI で書かれていること、確かめたことと確かめていないこと、文章や雛形を使うときの決まりを示すページである。この辞典は Anthropic の公式の教材ではない。

## AI で書いていることと確かめ方 {#ai-writing}

この辞典の本文は、AI（Claude）が書いている。人の手で一文ずつ書いたものではない。作者が目を通すのは、このページと、ライセンスや公開の約束にかかわる文だけである。ほかのページの本文を作者が読んで承認する手順はない。

本文は、次の流れで作り、確かめている。

| 工程 | 担当 | すること |
| --- | --- | --- |
| 書く | AI の担当 | 目次の項目、調査資料の該当の節、出典の一覧、数値ファイルの該当の項目を読んで書く。記憶で書かない。数値・既定値・名称・成熟度・大会の規則のように変わりやすい値は、本文に手で書かない。出典と確認日を付けて数値ファイルに置き、道具が本文に写す |
| 分かりやすさの確認と直し | 書いた担当とは別の AI の担当 | 冒頭だけで用が足りるか、節を 1 つだけ読んで通じるか、判断が書いてあるか、薄い節がないかを読んで指摘し、直す |
| 機械の検査 | 道具 | 形式、リンク、道具が書いた部分と数値ファイルの一致、文体と表記、出典の記録、図と雛形の形を調べる |
| 方針の文の承認 | 作者 | このページ、ライセンス、冒頭とフッターの非公式の文、公開の約束にかかわる文を読んで承認する |

確かめていないことも、次のとおり書いておく。

- 本文の事実と出典は、ページごとに検証の担当を置いて照らし直していない。本文は、公式の文書などを読んだ調査の報告と数値ファイルに基づく。ただし、各文を一次資料と 1 つずつ照らし直す確認は行っていない。
- 雛形（設定・フック・スキル・プロンプトなど）は、実機で動かして確かめていない。道具で調べるのは、形と設定のキーの綴りだけである。動作を確かめていない旨は、載せた雛形に添える。
- 安全とデータにかかわる雛形は、守りとして頼る前に、自分の環境で確かめる。

AI が書いた文は、もっともらしい誤りを含みうる。大事な箇所は、使う前に公式の文書で今の記述を確かめる。確認日のないページ（下書きの帯が出るページ）は、特に確かめてから使う。確認日と期限切れの注意書きの読み方は、<!-- link:begin how-to-use#freshness -->[この辞典の引き方 › 確認日と期限切れの注意書き](how-to-use.md#freshness)<!-- link:end -->にある。信用してよいかの見方は、<!-- link:begin how-to-use#trust -->[この辞典の引き方 › 信用してよいかの見方](how-to-use.md#trust)<!-- link:end -->にある。

## 段階「完成」の意味 {#done}

ページには段階がある。書き進み具合を表すもので、<!-- link:begin how-to-use#stage -->[この辞典の引き方 › 段階・下書きの帯・「準備中」の題名](how-to-use.md#stage)<!-- link:end -->に画面での見え方がある。この節は、段階の意味のうち、確かめた範囲に関わる部分を示す。

| 段階 | 意味 |
| --- | --- |
| draft（下書き） | 書き終え、機械の検査でエラーがないページ。帯は「下書き・未検証」で、確認日と版はまだない |
| reviewed（分かりやすさ確認済み） | 書いた担当とは別の担当が、分かりやすさを確かめ直したページ。本文の事実を一次資料と照らし直した、という意味ではない |
| done（完成） | 制作をまとめる担当（AI）が、機械の検査が 0 件で、未解決の指摘がないことを確かめたページ |

「完成」は、次のことを意味しない。

- 作者がすべてを確かめた、という意味ではない。
- 本文の事実を、1 つずつ一次資料と照らし直した、という意味ではない。この辞典は、そうした確認をしていない（[AI で書いていることと確かめ方](#ai-writing)の節）。
- 内容が今も新しい、という意味ではない。完成のページも、期限の日を過ぎれば、期限切れの注意書きが出る。

確認日のバッジは、出典を読み直したページにだけ付く。分かりやすさ確認済みのページでも、出典を読み直していなければ、確認日はなく「未検証」と出る。

## 出典の示し方（訳して載せない・写さない） {#citations}

ページ末尾の「参考」の節は、そのページが材料にした資料の一覧で、確認日を添える。道具が出典の記録から作るので、手では書かない。数値・既定値・名称・大会の規則は、数値ファイルから写し、確認日が付く。表では出典も付く。

出典の扱いには、次の決まりがある。

- 公式の文書は、訳して載せない。ほかの記事の文も転載しない。文は自分で書き、元の資料を参考に残す。原文を引くときは、引用として示す。
- 公式の文書は、日本語版があれば日本語版の題名で書く。リンクは、転送された先の URL にする。
- 研究の結果は、研究の名・公刊の年・対象（モデル・領域）を添える。小さな研究は傾向として書く。自己申告の数値は「自己申告」、根拠の弱い数値は「経験則」と書く。根拠の強さの印は、<!-- link:begin how-to-use#evidence -->[この辞典の引き方 › 根拠の強さの書き分け](how-to-use.md#evidence)<!-- link:end -->にある。
- 実在の人物や団体は、一次資料で確かめたことだけを、出典付きで書く。失敗例・古い助言・評価の否定的な文脈では、個人や著作を名指ししない。本人が自分の経験を振り返った記事は、本人の言葉として紹介する。
- 第三者のツール・書籍・講座は、例や出典として名前を出すだけで、評価や推薦をしない。公式の教材は案内する。
- 大会の規則は、版・確認日・類型・規則へのリンクだけを載せる。条文は要約しない。一次資料で確かめられない版は、「未確認」と書く。

## AI の利用を断るサイトを資料にしない {#noai}

この辞典は、AI の利用を断るサイトを、制作で使う資料にしない。AI に読ませないということである。atcoder.jp と codeforces.com は、AI の利用を断る指定を出しているので開かない。リンクは張る。

ほかのドメインは、`tools/check_noai.py` で確かめてから資料にする。見るのは、ページの `noai`・`noimageai` の指定、応答の `X-Robots-Tag`、`robots.txt` の指定である。Anthropic のクローラを名前で挙げてサイト全体を禁じるドメインは、断るドメインと同じ扱いで、資料にしない。そのサイトの写しを経由して読むことも同じである。名前のないクローラ全部への禁止だけのドメインと、一部のパスだけを禁じるドメインは、断るものとは見なさない。主催者の公式 X の投稿は出典にしてよい。投稿の本文だけを読み、投稿の中のリンクはたどらない。

この確認は、新しいドメインを資料にするときだけ行う。サイトの指定は変わりうるが、定期にやり直すとは約束しない。

読者が自分の AI に何を読ませてよいかは、各サイトの規約に従う。この辞典は、その可否を判断しない。

この辞典は Anthropic の公式の教材ではない。作者は yuukougun である。サイトの上部とフッターにも同じことを書いている。Anthropic のロゴと意匠はまねない。

この辞典の記述と公式の文書が食い違うときは、公式の文書を優先し、食い違いを報告してほしい。公式の文書や教材との使い分けは、<!-- link:begin how-to-use#official-docs -->[この辞典の引き方 › 公式の文書・公式の教材との役割分担](how-to-use.md#official-docs)<!-- link:end -->にある。

## 安全と法律についての注意 {#disclaimers}

- この辞典は、安全を保証するものではない。安全の既定や雛形を示すが、読者の環境で安全が保たれることは保証しない。
- この辞典は、法的な助言ではない。法令の解釈と、社内規則の回避は書かない。契約・社内規則・大会の規則は、自分で原文を確かめる。
- 雛形は、動作を確かめていないものがある（[AI で書いていることと確かめ方](#ai-writing)の節）。安全とデータにかかわる雛形は、守りとして頼る前に、自分の環境で確かめる。

## 連絡と誤りの報告 {#contact}

連絡の窓口は、GitHub の Issue（<https://github.com/yuukougun/claude-atlas/issues>）である。誤りや古い情報、ページや症状の提案は、ここで受ける。GitHub のアカウントが要る。各ページの最下部にある「このページの誤りを報告する」から開くと、ページの題名・URL・確認日・更新日が入る。

報告には、次のことを書いてほしい。

- どのページの、どの記述か（題名と URL）。
- そのページの確認日と版（下書きのページは「未検証」）。
- 何が違うか。食い違う公式の文書の URL があれば添える。読んだ日と版があれば、それも添える。

Issue は公開される。秘密の情報、個人の情報、認証情報は書かない。

報告への返事と、直す時期は約束しない。この辞典のサイトには、アクセスの解析を入れていない。報告の書き方の案内は、<!-- link:begin how-to-use#report -->[この辞典の引き方 › 誤りや古い情報の報告](how-to-use.md#report)<!-- link:end -->にある。
